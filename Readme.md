# Smiles Campana

Sitio web y sistema de gestión del consultorio odontológico Smiles Campana.

- **v1/**: primera versión (plantilla Bootstrap + jQuery, datos en el navegador). Se conserva como referencia.
- **v2/**: versión actual (sitio mobile-first, cuentas de pacientes, intranet con roles y odontograma interactivo sobre Supabase). Ver `v2/README.md`.
